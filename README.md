# Template — Next.js app

GitHub **template repository** for new Next.js apps under [Khaled-Abdelbaset](https://github.com/Khaled-Abdelbaset).

## Use this template

1. GitHub → **Use this template** → create `your-app`.
2. Clone: `git@github.com-khaled-abdelbaset:Khaled-Abdelbaset/your-app.git`
3. Set git email: [GIT_IDENTITY.md](https://github.com/Khaled-Abdelbaset/engineering-standards/blob/main/docs/GIT_IDENTITY.md)
4. `npm ci`, `npm run dev`

CI uses `reusable-node-ci.yml` with `flavor: next`. See [CONTRIBUTING.md](CONTRIBUTING.md).
